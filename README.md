 Étapes du travail

1️⃣ Analyse générale du fichier

Le fichier est très grand.

J’ai vérifié le nombre total de colonnes et leurs noms pour bien comprendre la structure.

2️⃣ Analyse de la colonne surface_reelle_bati

J’ai vérifié le contenu de la colonne pour trouver les valeurs manquantes ou les erreurs.

Certaines valeurs contenaient des symboles comme “m²” ou des espaces.

Cette étape n’était pas demandée, mais importante pour garantir la fiabilité du résultat.

3️⃣ Filtrage demandé

J’ai filtré uniquement les logements dont la surface réelle est entre 9 et 14 m² (bornes incluses).

Le travail a été fait en Python avec Visual Studio Code.

📊 Résultats

Un fichier Excel propre et lisible avec le tableau filtré.

Un rapport HTML clair avec les statistiques et un aperçu des premières lignes.

Un fichier texte (output.txt) résumant la méthode utilisée.
